运维数字孪生：语义基础与落地实践的系统综述

Operational digital twins in the built environment: A systematic review of semantic infrastructure and deployment practice

【研究】按 PRISMA 方法，从 2,839 条记录中筛选 46 项研究，分析运维数字孪生的语义集成与系统连接。 【发现】应用集中于环境质量与能源；跨建筑迁移和外部工作流连接仍有不足。 【阅读价值】适合研究 BIM—知识图谱—运维系统的集成架构。 【局限】结论来自纳入的文献，不能等同于所有工程部署的实测表现。

IFCMemoryBench：BIM 智能体能否记住项目上下文？

IFCMemoryBench: Evaluating Long-Term Memory of LLM-Based Agents in BIM Information Retrieval

【研究】用 19 个项目的 143 项多会话任务，评测智能体结合历史对话与 IFC 查询回答问题的能力。 【发现】在作者设定的实际部署式信息摄取范围内，最佳系统回答准确率为 32.4%。 【阅读价值】适合 BIM 问答助手、项目知识库与长期记忆研究。 【局限】仅代表论文评测的任务与系统；arXiv 版本不等同于期刊同行评审结论。

BIM-Edit：用自然语言修改 IFC 模型的能力评测

BIM-Edit: Benchmarking Large Language Models for IFC-Based Building Information Modeling

【研究】构建 324 项编辑任务，分别考察模型修改后的几何准确性、语义有效性和拓扑一致性。 【发现】作者评测中最佳平均分为 49.5%，没有模型完全解决超过 3.4% 的任务。 【阅读价值】可作为 BIM 自动建模与模型编辑工具的验证思路。 【局限】分数依赖该基准和被测模型，不能作为所有 BIM 自动化工具的通用准确率。

从历史 BIM 模型学习构件参数：机器学习决策支持

Machine learning-based decision support framework for BIM component specification

【研究】从 3 个 Revit 项目提取 5,763 个门实例，利用空间关系和随机森林预测门的规格属性。 【发现】部分项目内预测表现较好；跨项目受命名差异、类别不均衡和标签不匹配影响。 【阅读价值】适合构件推荐、历史模型复用和数据标准化研究。 【局限】只覆盖特定项目及构件，向其他建筑类型或构件迁移仍需验证。

Qwen-BIM: developing large language model for BIM-based design with domain-specific benchmark and dataset

【研究】提出 BIM 设计任务评测基准、模型转文本数据构造方法和领域微调策略。 【发现】作者报告微调模型相对基座模型的 G-Eval 平均分提升 21.0%。 【阅读价值】适合 BIM 专用大模型训练与领域评测研究。 【局限】提升针对论文中的评测设置，不代表真实工程设计准确率；当前链接为预印本。
